IAM Scenario Exploration & Evaluation Framework
About

Paris-aligned SCI scenarios compared by relative feasibility and desirability.

This dashboard presents the IAMEE framework applied to vetted GW2, GW3, and GW4 scenarios from the Scenario Compass Initiative. It compares global and R10 regional feasibility and desirability scores across the framework dimensions.

The SCI run uses the available R10 data, applies documented variable substitutions, and excludes the dietary-change and electricity-price indicators where SCI coverage was insufficient.
